# 💻 Bornfire Frontend

This is the user interface for Bornfire, built with **Vite**, **React**, and **Tailwind CSS**. It follows a **Neo-Brutalist** design system with bold borders and vibrant colors.

## 🛠️ Configuration

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Environment Variables**:
   Create a `.env` file in this folder and add your Supabase keys:
   ```env
   VITE_SUPABASE_URL=your_supabase_url
   VITE_SUPABASE_ANON_KEY=your_supabase_key
   ```

3. **Run Development Server**:
   ```bash
   npm run dev
   ```

## 🎨 Design System

We use a custom Neo-Brutalist style defined in `src/index.css`.
- **Borders**: `4px solid black`
- **Shadows**: Hard offsets `4px 4px 0px 0px #000`
- **Colors**: Cyber Yellow, Neon Pink, Electric Teal.
